# Approximation — Hardness of Approximation

**Purpose:** Formalize approximability, gap creation, PCP connection up to inapproximability.

**Files:**
- `ApproximationComplexity.lean`
- `ApproximationCollection.lean`

**Methodology:** Approximation ratio definitions, gap-preserving reductions, connection to CircuitComplexity Shannon bounds, Hastad-type linearity testing skeleton.

**Results:** Definitions of APX, PTAS, APX-hardness, approximation lower bounds via circuit counting. Used by PvsNP.Barriers for Natural Proofs largeness discussion.

**Dependencies:** PvsNP.Complexity, Mathlib.
