# Probabilistic — BPP, RP, Randomness

**Purpose:** Formalize probabilistic complexity, Chernoff, Adleman's BPP⊆P/poly.

**Files:**
- `ProbabilisticComplexity.lean`

**Methodology:** Probabilistic TM, error bounds 1/3, amplification via Chernoff, Adleman trick via counting + union bound, Sipser-Lautemann BPP⊆PH skeleton.

**Results:** BPP, RP, coRP definitions, BPP⊆P/poly, BPP⊆PH. Provides randomness techniques that bypass relativization but not natural proofs.

**Dependencies:** PvsNP.Complexity, Mathlib Probability.
